# 📅 Deadline Tracker AI

### AI-Powered Academic Deadline Assistant

Deadline Tracker AI is an AI-powered academic assistant that helps students
extract important deadlines from academic documents such as syllabi,
timetables, assignment sheets, exam schedules, and academic notices.

Students can upload an image, ask questions about the extracted deadlines,
and send a concise deadline digest directly to Telegram.

---

## 🚀 Features

- 📸 Upload academic schedule images
- 🧠 Gemini Vision-powered deadline extraction
- 📅 Identify assignments, exams, projects, and submission dates
- ⏰ Extract available dates and times
- 💬 Ask questions about extracted deadlines
- 📊 Organize deadlines chronologically
- 📤 Send deadline summaries to Telegram
- 🔐 Secure API credentials using Streamlit Secrets
- 🛡️ Prevent secrets from being committed to GitHub
